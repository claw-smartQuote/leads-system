# 六合彩自動核對服務

## 功能
每期六合彩開獎後自動搜索結果，核對用戶固定號碼，並通過 WhatsApp 發送通知。

## 用戶固定號碼
**6, 13, 14, 29, 45, 46**

## 開獎時間
- 每週 **二、四、六** 晚上 9:30 攪珠
- 自動核對時間：開獎當晚 **10:15 PM** (留足時間等結果公佈)

## 核對規則
| 獎項 | 中獎條件 | 獎金 |
|------|---------|------|
| 頭獎 | 6個攪出號碼 | 不少於 $8,000,000 |
| 二獎 | 5個攪出號碼 + 特別號碼 | 按注數分 |
| 三獎 | 5個攪出號碼 | 按注數分 |
| 四獎 | 4個攪出號碼 + 特別號碼 | $9,600 |
| 五獎 | 4個攪出號碼 | $640 |
| 六獎 | 3個攪出號碼 + 特別號碼 | $320 |
| 七獎 | 3個攪出號碼 | $40 |

## 文件
- `check_result.py` - 核對腳本
- `config.json` - 用戶號碼與設定

# 港車北上-報價系統

永誠財產保險 - 港車北上汽車保險報價系統
支持燃油車與新能源車自動報價

## 功能

- 🔥 燃油车险报价（V.32 费率表）
- ⚡ 新能源车险报价（V.12 费率表）
- 📊 自动计算交强险、商业险、附加险
- 🎂 **根据车龄自动计算商业险折扣（仅燃油车）**
- 🚗 **新能源车固定九折，不根据车龄变化**
- 🛡️ **驾意险计算（30万/50万保额，按总座位数）**
- 🤖 WhatsApp 报价机器人

## 商业险折扣规则

### 燃油车（根据车龄）

| 车龄 | 折扣 |
|------|------|
| 3年以上 | 七折 (0.7) |
| 2年以上 | 八折 (0.8) |
| 2年以下（含1年内）| 九折 (0.9) |

### 新能源车

| 车龄 | 折扣 |
|------|------|
| 所有车龄 | 固定九折 (0.9) |

## 交强险金额（固定）

| 车辆类型 | 交强险金额 |
|----------|-----------|
| 6座以下个人/企业 | 665元 |
| 6-10座个人/企业 | 770元 |

## 驾意险费率

| 保额 | 每位乘客 |
|------|----------|
| 30万 | 40元 |
| 50万 | 60元 |

**座位数计算**：总座位数 = 乘客数 + 1（司机）

**计算公式**：
- 30万驾意险 = 座位数 × 40元
- 50万驾意险 = 座位数 × 60元

## 支持的险别

### 基础险别（默认包含）
- 交强险（固定金额）
- 第三者责任险（100-500万）
- 医保外用药（三者）（10万默认）
- 道路救援（12次免费）

### 可选附加险
- **医保外用药（三者）** - 默认10万，可选10万/20万/不投保
- 车上人员（司机/乘客）- 默认不投保
- 驾意险（30万/50万）- 默认不投保

## 使用方法

### 1. WhatsApp 报价机器人（推荐）

直接发送消息给 AI 助手：

**基本格式：**
```
报价 [车牌号] [燃油車/新能源車] [車輛類型] [乘客數] [車齡] [第三者保額] [選項]
```

**示例：**
- `报价 粤B12345 燃油车 6座以下个人 4人 3年 300万`（基本报价，医保外10万）
- `报价 粤B12345 燃油车 6座以下个人 4人 3年 300万 医保外20万`（医保外20万）
- `报价 粤B12345 燃油车 6座以下个人 4人 3年 300万 不含医保外`（不含医保外）
- `报价 粤B12345 燃油车 6座以下个人 4人 3年 300万 车上人员 50万驾意`（全险）
- `报价 港车A123 新能源 6座以下个人 4人 2年 200万`（新能源）

**选项说明：**
- `医保外10万` / `醫保外10萬` - 医保外用药10万保额（默认）
- `医保外20万` / `醫保外20萬` - 医保外用药20万保额
- `不含医保外` / `不含醫保外` - 不投保医保外用药
- `车上人员` / `車上人員` - 投保车上人员险
- `30万驾意` / `30萬駕意` - 投保30万驾意险
- `50万驾意` / `50萬駕意` - 投保50万驾意险

**默认参数：**
- 使用性质：6座以下个人
- 乘客数：4人
- 车龄：3年
- 第三者保额：300万
- **医保外用药：10万**
- 车上人员：不投保
- 驾意险：不投保

```python
print(f"商业险: {quote.commercial_total}")
print(f"总计: {quote.total_premium}")
```

## 计算逻辑

```python
# 燃油车商业险折扣
def calculate_discount(vehicle_age):
    if vehicle_age >= 3: return 0.7  # 七折
    elif vehicle_age >= 2: return 0.8  # 八折
    else: return 0.9  # 九折（含1年内）

# 新能源车商业险折扣（固定）
discount = 0.9  # 九折

# 保费计算
保费 = 基础保费 × 折扣

# 交强险（固定金额）
6座以下 = 665元
6-10座 = 770元

# 驾意险
total_seats = 乘客数 + 1（司机）
30万驾意险 = total_seats × 40
50万驾意险 = total_seats × 60
```

## 车龄计算方式（两种方法）

### 方法1：直接输入车龄
```python
quote = system.generate_quote_by_age(
    license_plate="粤B12345",
    vehicle_fuel_type="燃油车",
    vehicle_category="6座以下个人",
    passenger_count=4,
    vehicle_age=3.5,  # 直接输入车龄
    third_party_limit=300
)
```

### 方法2：通过登记年月计算
```python
quote = system.generate_quote_by_year_month(
    license_plate="粤B12345",
    vehicle_fuel_type="燃油车",
    vehicle_category="6座以下个人",
    passenger_count=4,
    register_year=2021,   # 登记年份
    register_month=6,     # 登记月份
    third_party_limit=300
)
```

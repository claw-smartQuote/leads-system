# 港車北上資料庫歸檔技能

## 功能描述
自動處理客戶資料檔案，識別內容並歸檔到統一資料庫。

## 工作流程

### 觸發條件
當 `等待命名的` 資料夾內有新資料夾時，自動執行。

### 執行步驟

**1. 識別臨時資料夾**
- 監控 `~/Desktop/等待命名的/` 目錄
- 識別所有 `臨時檔案XX` 資料夾

**2. 分析檔案內容**
- 從 `*交.pdf` (交強險) 提取：
  - 客戶名字（被保险人）
  - 車牌號碼
  - 保險到期月份
- 從 `*商.pdf` (商業險) 確認資料
- 從 RTF/TXT 檔案獲取額外客戶資訊

**3. 歸檔到統一資料庫**
- 資料庫位置：`~/Desktop/港車北上客戶資料庫/`
- 資料夾命名格式：`到期月份_車牌號碼_客戶名字（簡體中文）`
  - 例如：`02_JC829_赵克宏`
  - 例如：`09_YP4456_萧启洋`

**4. 複製並清空**
- 使用 `cp` 複製檔案到目標資料夾
- 複製完成後，**立即刪除臨時資料夾內所有檔案**（`rm -rf 臨時檔案/*`）
- 將空嘅臨時資料夾移回桌面

**5. 權限設定**
- 所有資料夾權限設為 `777`（所有人可讀寫）

### 資料庫結構
```
📁 港車北上客戶資料庫/
├── 02_JC829_赵克宏/
│   ├── JC829交.pdf      # 交強險
│   ├── JC829商.pdf      # 商業險
│   ├── JC829驾.pdf      # 駕駛證
│   ├── *.jpg            # 證件照片
│   └── *.rtf           # 客戶聯絡資料
├── 09_YP4456_萧启洋/
│   └── ...
```

## PDF 文字提取方法
```python
import fitz, re
doc = fitz.open('交強險.pdf')
text = ''
for page in doc:
    text += page.get_text()
doc.close()

# 提取起保日期 - 匹配 "起" 和 日期在同一區塊
# 保險期間格式: "起 2025-08-06" 和 "至 2026-08-05"
match = re.search(r'自\s*(\d{4}-\d{2}-\d{2})', text)
if match:
    start_date = match.group(1)  # e.g. "2025-08-06"
    start_month = start_date.split('-')[1]  # "08"
```

⚠️ **重要**：有啲 PDF 格式混乱，要睇清楚「起保日期」係邊個，唔好錯誤匹配其他日期！

## 重要提醒
- ❗ 歸檔完成後**必須清空臨時資料夾**，唔好留任何檔案
- ❗ 客戶名字使用**簡體中文**
- ❗ 到期月份格式：`02`（2月）、`09`（9月）
- ✅ 自動檢測並處理所有臨時資料夾
- ✅ 完成後即時將臨時資料夾退回桌面

## 臨時資料夾
- 桌面應有：`臨時檔案01`、`臨時檔案02`、`臨時檔案03`
- 權限：`777`

## 技能觸發（自動執行，無需提醒）

❗ **關鍵：每當察覺 `等待命名的` 內有臨時資料夾，必須立即執行以下流程：**

1. **立即識別** - 讀取 PDF 提取車牌、客戶名（簡體）、到期月份
2. **即時歸檔** - 建立正確命名的資料夾，複製檔案
3. **清空歸位** - 臨時資料夾內所有檔案必須清除，然後移回桌面

**牢記：這是全自動流程，用戶無需提醒。每次都是最後一次提醒。**

# 港車北上保險知識庫

*基於永誠財險三種保單樣本分析*

---

## 概述

港車北上需要三種保險組合：
1. **交強險**（法定強制）
2. **商業第三者責任險**（建議投保）
3. **駕乘人員意外傷害險**（建議投保）

---

## 一、交強險（機動車交通事故責任強制保險）

### 基本資訊
- **性質**：法定強制保險，必須購買
- **保險公司**：永誠財產保險股份有限公司
- **適用範圍**：中國境內（不含港澳台）

### 保障內容

| 責任項目 | 賠償限額 |
|---------|---------|
| 死亡傷殘賠償 | 180,000元 |
| 醫療費用賠償 | 18,000元 |
| 財產損失賠償 | 2,000元 |
| **無責任賠償** | |
| 無責死亡傷殘 | 18,000元 |
| 無責醫療費用 | 1,800元 |
| 無責財產損失 | 100元 |

### 參考保費
- 非營業6-10座客車：約¥770/年
- 浮動比率：根據出險記錄調整（0%起）

### 重要條款
1. **一次性交清保費**
2. **48小時內通知義務**：事故發生後須及時通知保險人
3. **所有權轉移須辦理變更**：否則可能拒賠
4. **異議期限**：收到保單48小時內可提出異議

### 限制
- 保額較低（總額20萬），嚴重事故可能不足
- 不保障本車車損
- 不保障本車人員傷亡

## 二、商業第三者責任險

### 基本資訊
- **性質**：商業補充保險（非強制，強烈建議投保）
- **主險**：第三者責任保險
- **常用附加險**：
  - 醫保外用藥責任險
  - 道路救援服務特約條款

### 保障內容（樣本方案）

| 險種 | 保額 | 說明 |
|-----|------|-----|
| 第三者責任險 | 300萬元 | 超出交強險部分 |
| 醫保外用藥責任險 | 10萬元 | 社保外藥物費用 |
| 道路救援服務 | 12次/年 | 免費贈送 |

### 參考保費
- 三者300萬 + 醫保外用藥10萬：約¥941/年

### 重要條款
1. **零免賠率設計**（部分產品）
2. **事故通知**：48小時內通知，保留第一現場
3. **賠付方式**：可以不限於實物方式賠付
4. **代位求償**：可先賠付再向第三方追償

### 責任免除（不賠情況）
- 肇事逃逸
- 酒後/吸毒駕駛
- 無證駕駛
- 車輛被盜搶期間
- 競賽、測試期間
- 維修保養期間

## 三、駕乘人員意外傷害險

### 基本資訊
- **性質**：人身意外保險（團體險，以車為單位）
- **保障對象**：駕駛及乘坐該車輛的人員
- **被保險人數**：按核定座位數（如7人）

### 保障內容（樣本方案）

| 保障項目 | 每人保額 | 總保額(7人) |
|---------|---------|------------|
| 意外傷害身故/傷殘 | 30萬元 | 210萬元 |
| 意外傷害醫療 | 10萬元 | 70萬元 |
| 住院津貼 | 1.8萬元 | 12.6萬元 |
| 骨折津貼 | 共用住院津貼 | — |
| 法定節假日加倍 | 20萬元 | 140萬元 |

### 給付細節
- **住院津貼**：每日100元，免賠3天，單次最多90天，累計180天
- **醫療費用**：每次事故免賠100元，賠付比例80%
- **傷殘鑑定**：須於意外發生後180日內完成

### 參考保費
- 7座家庭自用客車：約¥280/年

### 重要限制
1. **地域限制**：僅承擔中國大陸境內（不含港澳台）事故
2. **除外責任**：無證駕駛、酒後駕車、無有效行駛證
3. **醫院限制**：中國大陸二級及以上公立醫院普通病區
4. **未成年人限額**：
   - 未滿10周歲：身故保額不超20萬
   - 10-18周歲：身故保額不超50萬

## 港車北上投保建議

### 必投保組合（基礎版）
- ✅ 交強險（法定必須）
- ✅ 商業三者險300萬（強烈建議）
- ✅ 駕乘險（建議投保）
- **總保費**：約¥2,000/年

### 全面保障組合（進階版）
- 上述基礎版 +
- 車損險（如車齡較新）
- 三者險提高至500萬或1000萬
- 附加險（玻璃單獨破碎、自燃等）

### 特別注意事項

1. **地域限制**
   - 所有保險僅在大陸境內生效
   - 香港境內事故不受保障
   - 跨境行駛需確保保險銜接

2. **報案時效**
   - 事故發生後48小時內必須通知保險公司
   - 保留第一現場證據

3. **醫療機構**
   - 必須為中國大陸二級及以上公立醫院
   - 私立醫院或香港醫院費用可能不賠

4. **理賠流程**
   - 報案 → 定損 → 提交資料 → 審核 → 賠付
   - 爭議處理：向保險公司所在地法院訴訟

## 常見問題

### Q1: 港車北上必須買哪些保險？
A: 交強險是法定強制，必須購買。商業險和駕乘險雖非強制，但強烈建議投保以獲得充足保障。

### Q2: 交強險保額不夠怎麼辦？
A: 可投保商業第三者責任險作為補充，建議保額300萬或以上。

### Q3: 本車人員受傷誰來賠？
A: 交強險和商業三者險都不保障本車人員，需要投保駕乘人員意外傷害險。

### Q4: 車輛損壞怎麼辦？
A: 上述三種保險都不保障本車損失，如需保障需額外投保車損險。

### Q5: 保險可以在香港理賠嗎？
A: 不可以，港車北上保險僅在中國大陸境內有效，理賠需在大陸處理。

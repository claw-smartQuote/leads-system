# Zurich 私家車保險（電動車）條款摘要

**文件編號**: ZPP-002-05-2024E  
**保險公司**: Zurich Insurance Company Ltd（蘇黎世保險有限公司）  
**適用車輛**: 私家車 / 電動車（Private Motor Car / Electric Vehicle）

---

## 📋 保單結構

### 三大保障類型

| 保障類型 | 英文名稱 | 包含內容 |
|---------|---------|---------|
| **綜合保險** | Comprehensive | 第1節（車損）+ 第2節（第三者責任）+ 第3節（醫療費用） |
| **第三者保險** | Third Party Only | 僅第2節（第三者責任） |
| **第三者火險及盜竊** | Third Party Fire & Theft | 第1節（僅火災、盜竊等）+ 第2節 |

---

## 🚗 第1節：車輛損失或損壞保障

### 保障範圍
- 車輛本身、配件、備用零件的損失或損壞
- **電動車電池**（屬於受保財產）
- **高級駕駛輔助系統（ADAS）**造成的損壞也受保（需經運輸署批准使用）

### 賠償上限
- 車輛當時市價 **或** 保單列明估價，以較低者為準
- 拖車費用：不超過維修費用的20%

### 折舊扣減（Betterment Contribution）

| 車齡（從出廠年份計算） | 扣減比例 | 備註 |
|---------------------|---------|------|
| 不超過1年 | 0% | - |
| 1-2年 | 10% 或 0% | 符合條件可獲0%扣減 |
| 2-3年 | 15% 或 0% | 符合條件可獲0%扣減 |
| 3-4年 | 20% | - |
| 4-5年 | 25% | - |
| 5-6年 | 30% | - |
| 超過6年 | 超過30% | 根據零件損壞時價值計算 |

**獲得0%折舊扣減的條件**：
1. 受保人為第一或第二任登記車主
2. 首次或第二次登記必須在車輛製造日期起12個月內完成
3. 車齡不超過3年（以車牌登記文件為準）
4. 保單列明估價至少等於「新車替換價值」（New Replacement Value）
   - 新車替換價值 = 同款全新電動車市值減去首次登記稅（FRT）優惠

### 自付額（Excesses）

**一般情況（非盜竊）**：
- **一般自付額**（General Excess）：保單列明金額

**額外自付額（可累加）**：
| 情況 | 額外自付額 |
|------|----------|
| 非指定司機駕駛 | 非指定司機自付額（Unnamed Driver Excess） |
| 25歲以下司機 | 年輕司機自付額（Young Driver Excess） |
| 持牌少於2年 | 經驗不足司機自付額（Inexperienced Driver Excess） |
| 泊車時損壞 | 泊車損壞自付額（Parking Damage Excess） |

**盜竊/企圖盜竊**：
- 盜竊損失自付額（Theft Loss Excess）

**豁免**：
- 火災、自燃、閃電或爆炸造成的損失（不涉及其他事故）可豁免自付額

### 第1節除外責任
- 間接損失
- 折舊、自然損耗、機械或電氣故障
- **電池容量或性能損失**（重要：電池老化不賠）
- 輪胎損壞（除非同時損壞其他部分）

---

## 👥 第2節：第三者法律責任保障

### 保障範圍
- 第三者人身傷亡（死亡或身體傷害）
- 第三者財產損壞
- 包括裝卸貨物時發生的事故
- **ADAS系統造成的損害也受保**

### 賠償上限（每次事故）
- **第三者死亡或人身傷害**：保單列明限額
- **第三者財產損壞**：保單列明限額

### 自付額
- **第三者財產損壞自付額**（Third Party Property Damage Excess）
- **年輕司機額外自付額**（25歲以下）
- **經驗不足司機額外自付額**（持牌少於2年）

### 第2節除外責任
- 受保人僱員在受僱期間的傷亡（應由勞工保險保障）
- 受保人或其家庭成員的財產損壞
- 香港以外法院判決（除非為符合法例要求）
- 機場禁區內駕駛（除非為符合法例要求）
- 恐怖主義行為

---

## 🏥 第3節：醫療費用賠償

### 保障範圍
- 受保人、指定司機（非受保人）或乘客因意外受傷的合理醫療費用

### 賠償上限
- 保單列明的「第3節賠償限額」

---

## 💰 第6節：無索償折扣（Claim-free Discount, CFD）

### 折扣等級

| 無索償年數 | 折扣組別 | 基本折扣率 |
|-----------|---------|-----------|
| 少於1年 | - | 0% |
| 1年 | - | 30% |
| 連續2年 | - | 35% |
| 連續3年 | - | 45% |
| 連續4年 | - | 50% |
| 連續5年或以上 | - | 60% |

**重要說明**：
- 上述百分比僅為組別參考，**實際折扣由保險公司根據車主年齡、車齡等因素決定**

### 索償後的影響

| 原折扣組別 | 1宗索償後 | 多於1宗索償 |
|-----------|----------|------------|
| 45%或以下 | 取消所有折扣（0%） | 取消所有折扣（0%） |
| 50% | 降至30% | 取消所有折扣（0%） |
| 60% | 降至35% | 取消所有折扣（0%） |

### 豁免取消折扣的情況
即使提出索償，以下情況可保留折扣：
1. 能提供第三方司機被定罪的法庭證明；**且**
2. 受保人及司機簽署確認書，確認沒有被檢控、沒有收到傳票；**且**
3. 如之後被檢控，必須立即通知保險公司

### NCD轉移
- 轉讓保單給新車主時，原車主可在12個月內將累積的NCD用於其他私家車保單

---

## ⚠️ 第7節：一般除外責任

### 不承保的情況
1. **地域限制**：香港特別行政區以外（受保地域僅限香港）
2. **違法使用**：出租、賽車、速度測試、與汽車貿易相關用途
3. **戰爭、暴動、罷工、內亂**
4. **核輻射、核燃料污染**
5. **恐怖主義行為**
6. **酒後或藥後駕駛**：
   - 被定罪酒後/藥後駕駛
   - 呼氣/血液/尿液酒精濃度超過法定上限
   - 拒絕提供測試樣本
7. **網絡攻擊**（Cyber Act）：任何未經授權、惡意或犯罪行為涉及電腦系統

## 🔑 重要術語

| 術語 | 定義 |
|------|------|
| **Insured Driver（受保司機）** | 受保人或其許可的人，必須持有有效駕駛執照 |
| **Geographical Area（受保地域）** | 香港特別行政區及其領海（包括海上運輸） |
| **Event（事故）** | 與車輛相關的單一事件或同一原因引起的一系列事件 |
| **Betterment（折舊）** | 新零件價值與損壞零件在事故時價值的差額 |
| **New Replacement Value（新車替換價值）** | 同款全新電動車市值減去首次登記稅優惠 |


## 2026-03-17 會話記錄

### 完成的工作

#### 28car.com 汽車保險潛客爬蟲修復
- **問題**: 用戶反饋爬蟲腳本無法從 28car.com 獲取數據
- **診斷過程**:
  1. 發現 28car.com 使用 Cloudflare 保護，阻擋無頭瀏覽器
  2. 網站使用 iframe 結構加載內容（主 frame 只有 505 bytes，內容在 https://dj1jklak2e.28car.com/sell_lst.php）
  3. 測試確認需要 `headless=False`（有頭模式）才能繞過 Cloudflare
  4. 表格結構複雜，前 30 行都是菜單/過濾器，真實車輛數據在後面

- **解決方案**:
  - 創建了 `run_scraper.py` - 使用有頭模式的可靠版本
  - 數據自動保存到桌面文件夾: `~/Desktop/汽車保險潛客數據/`
  - Excel 文件命名格式: `保險潛客數據_2026-03-17.xlsx`
  - 使用 SQLite 數據庫去重

- **關鍵發現**:
  - Frame 1 URL 模式: `https://dj1jklak2e.28car.com/sell_lst.php`（動態子域名）
  - 電話號碼通常在描述列中通過正則 `\d{4}[\s-]?\d{4}` 提取
  - 車型鏈接格式: `sell_dsp.php?h_vid=123456`

- **相關文件**:
  - `/Users/claw/.openclaw/workspace/insurance_leads_scraper/run_scraper.py` - 主腳本
  - `/Users/claw/Desktop/汽車保險潛客數據/` - 數據文件夾
  - `/Users/claw/Desktop/汽車保險潛客數據/leads_database.db` - SQLite 數據庫

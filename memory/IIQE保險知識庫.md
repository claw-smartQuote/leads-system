## 📚 Paper 1 - 保險原理及實務（核心章節）

### 第3章 保險原則（30% - 最重要）

#### 3.1 可保權益 (Insurable Interest)
- **定義**：某人與標的之間的法律認可關係
- **產生方式**：所有權、婚姻/家庭關係、債務/債權關係、僱傭關係、法律責任
- **何時需要**：索償時必須具有（人壽保險：訂約時必須具有）
- **轉讓**：人壽保單可轉讓予不具有可保權益的人

#### 3.2 最高誠信 (Utmost Good Faith)
- **與一般誠信分別**：
  - 一般合約：不須主動披露
  - 保險合約：主動披露所有重要事實
- **重要事實定義**：影響謹慎保險人決定是否承保或條件的事實
- **違反類別**：
  - 非披露 (Non-disclosure)
  - 失實陳述 (Misrepresentation)
  - 欺詐 (Fraud)
- **補救措施**：
  - 欺詐 → 合約無效，不退保費
  - 非故意失實陳述 → 合約無效，退回保費
  - 非故意非披露 → 按比例減少賠償

#### 3.3 近因 (Proximate Cause)
- **定義**：有效導致損失的原因，非時間上最近的原因
- **危險種類**：不保危險、受保危險、除外危險
- **原則應用**：
  - 單一原因：該原因是否受保
  - 連鎖事件：看最初原因
  - 多個同時原因：分擔賠償

#### 3.4 彌償 (Indemnity)
- **定義**：使被保險人回復至損失前的財務狀況，不可從中獲利
- **如何提供**：現金賠償、修理/重置、替代財產
- **委付**：全損時被保險人將財產權利轉讓給保險人

#### 3.5 分擔 (Contribution)
- **產生條件**：
  1. 同時存在多份保單
  2. 保障同一利益
  3. 保障同一風險
  4. 保障同一被保險人
- **適用方式**：按保額比例分擔

#### 3.6 代位 (Subrogation)
- **定義**：保險人賠償後取得被保險人對第三者的權利
- **不適用於**：人壽保險

### 第6章 保險業的規管架構（21%）

#### 保險業監管局 (IA)
- 監管機構：保險業監管局 (Insurance Authority)
- 《保險業條例》(IA) - 三重門檻制度：償付能力、本地資產、適當人選

#### 保險投訴局 (ICB)
- 處理索償投訴
- 可作出最高120萬港幣的裁決

#### 保險中介人規管
- **牌照類別**：個人持牌、業務代表、負責人
- **發牌條件**：適當人選、學歷/考試、持續培訓 (CPD)
- **重要規則**：
  - 只可向一間保險公司申請代理人資格
  - 可同時持有多間經紀委任

### 第2章 法律原則（16%）

#### 合約元素（6個）
1. 要約 (Offer)
2. 承約 (Acceptance)
3. 代價 (Consideration)
4. 訂約能力 (Capacity)
5. 合法性 (Legality)
6. 訂立法律關係的意向 (Intention)

#### 代理關係產生方式
- 委託、追認、必要、不容反悔 (Estoppel)

## 📚 Paper 2 - 一般保險

### 汽車保險
- **強制保險**：第三者人身傷亡責任（不少於1億港幣）
- **私家車保單結構**：
  - 第一部分：承保第三者責任
  - 第二部分：承保汽車損壞
- **綜合保險**：包括火災、盜竊、意外等
- **無索償折扣 (NCD)**：最高可達60%

### 健康保險
- **自願醫保計劃 (VHIS)**：保證續保至100歲、扣稅優惠
- **指引31**：規管醫療保險業務、公平待客原則

### 責任保險
- **僱主責任保險**（強制）：《僱員補償條例》規定
- **專業彌償保險**：適用於醫生、律師、會計師、保險中介人

### 水險
- **倫敦保險協會貨物條款 (ICC)**：
  - ICC (A)：全險，除特別列明除外
  - ICC (B)：列明危險
  - ICC (C)：有限保障

## 📚 Paper 3 - 長期保險

### 人壽保險產品
- **定期壽險 (Term)**：低保費、無現金價值
- **終身壽險 (Whole Life)**：終身保障、有儲蓄成分
- **儲蓄壽險 (Endowment)**：死亡保障 + 期滿生存給付
- **年金 (Annuities)**：將累積資金轉化為收入

### 重要條款
- **不可抗辯條款**：保單生效通常2年後，保險公司不得質疑有效性
- **不喪失價值條款**：現金價值、減額滿期、展期定期
- **冷靜期**：21天，可無條件取消並退還保費

### 核保風險分類
| 類別 | 說明 |
|------|------|
| 標準風險 | 按標準保費承保 |
| 優良風險 | 可獲保費折扣 |
| 次標準風險 | 需附加保費或限制 |
| 拒保風險 | 不可承保 |
